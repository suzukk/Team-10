# 10-р багийн Definition of Done (DoD)

> Төлөв: **ноорог** — багаараа хэлэлцэж баталгаажуулна.
> Төсөл: Үл хөдлөх хөрөнгө зарах, түрээслэх систем

"Ажил дууссан" гэж хэлэхийн тулд user story / даалгавар бүр дараах **бүх**
шалгуурыг хангасан байна.

## Код

- [ ] Код бичигдсэн, acceptance criteria бүрийг хангаж байгаа.
- [ ] Код feature branch дээр хийгдсэн, `main` руу шууд push хийгээгүй.
- [ ] Багийн кодын дүрмийг дагасан: `npx eslint .` алдаа, анхааруулгагүй.
- [ ] Нийтийн функц, класс, endpoint-д товч тайлбар (comment) бичигдсэн.

## Тест

- [ ] **Шинэ болон өөрчилсөн логикт нэгжийн тест (unit test) бичигдсэн.**
- [ ] **Бүх нэгжийн тест амжилттай давсан (`npm test` ногоон).**
- [ ] Хэвийн тохиолдлоос гадна хилийн тохиолдол (хоосон, сөрөг, буруу төрлийн
      утга) тестлэгдсэн.
- [ ] Integration тест (хамаатай бол) амжилттай.

## Хяналт ба нэгтгэл

- [ ] Pull Request нээгдсэн, тайлбартай.
- [ ] Багийн өөр нэг гишүүн code review хийж зөвшөөрсөн.
- [ ] CI pipeline (lint, build, test) ногоон.
- [ ] `main` руу merge хийгдсэн, conflict-гүй.

## Баримтжуулалт

- [ ] README эсвэл холбогдох баримт шинэчлэгдсэн (шинэ endpoint, тохиргоо,
      ажиллуулах заавар өөрчлөгдсөн бол).
- [ ] Trello/Kanban карт "Done" баганад шилжсэн.

## Нэгжийн тестийн талаарх тохиролцоо

Лабораторийн ажлын 5-р алхмын дагуу "код нэгжийн тестэд бүрэн давсан байх" нь
манай DoD-ийн **заавал** биелэх шалгуур болно. Тестгүй, эсвэл тест нь унасан
кодыг дууссан гэж үзэхгүй бөгөөд `main` руу merge хийхгүй. Боломжтой үед TDD
(Улаан → Ногоон → Рефактор) дарааллаар ажиллана: эхлээд унах тест бичиж, дараа
нь түүнийг давуулах хамгийн бага код бичээд, эцэст нь кодоо цэгцэлнэ.
