## Тайланд оруулах тайлбар

Багаараа "ажил дууссан" гэж хэзээ үзэхийг тодорхойлсон Definition of Done-ийн
жагсаалт боловсруулж, нэгжийн тест бичигдсэн бөгөөд бүгд давсан байхыг заавал
биелэх шалгуур болгосон. Дараа нь Jest суулгаж, `sum` функцийг TDD аргаар
хөгжүүлсэн: эхлээд `1 + 2 = 3` гэсэн тестийг бичиж ажиллуулахад функц байхгүй
тул унасан (Улаан), дараа нь функцийг бичихэд тест давсан (Ногоон). Хоёр дахь
давталтад "тоо биш өгөгдөл өгвөл алдаа заана" гэсэн шинэ шаардлагын тестийг
нэмэхэд дахин унаж, функцэд төрлийн шалгалт нэмсний дараа хоёр тест хоёулаа
давсан. Рефактор шатанд кодын бүтцийг өөрчлөх шаардлага гараагүй. TDD нь
шаардлагыг эхлээд тест хэлбэрээр тодорхойлж, зөвхөн түүнийг хангах хэмжээний код
бичүүлдэг тул илүүдэл кодгүй, өөрчлөлт бүр тестээр хамгаалагдсан байдаг гэдгийг
ойлгосон.
